Privacy

Last updated October 2026

The short version: images are sent to a server to be analysed, a small log is kept, and nothing is sold or used for advertising.

What the extension sends

  • When you right-click an image and choose "Analyze with AI Detector", the extension downloads that image, shrinks or converts it if needed, and uploads it to the server address in its settings. By default this is my hosted demo.
  • Passive Badge Mode is off by default. If you turn it on, the extension uploads images of 150 pixels or more from pages you visit (up to six per page) so it can badge them. Turn it off at any time in the popup.
  • The file name sent with an image is taken from the image address, so it can contain words from the original page.

What the server keeps

  • A prediction log: file name, verdict, confidence score, processing time and timestamp. The image itself is not saved.
  • A short-lived cache: a perceptual hash (a compact fingerprint) of the image with its result, so identical images are not analysed twice.
  • Feedback, only if you give it: when you press the up or down arrow, the file name, the verdict shown, its confidence, your answer and where it came from (playground or extension).
  • Your IP address is used to apply rate limits and may appear in hosting logs.

Feedback and human-reviewed labels may be used to measure how well the model is doing and to improve it.

What stays on your device

  • The extension stores its settings (server address, access key, mode, passive toggle) with Chrome's sync storage, which Chrome may sync across devices where you are signed in.
  • The web playground keeps your access key, a theme preference and an "intro seen" flag in your browser's local storage.

Third parties

  • The service runs on cloud hosting, database and cache providers that process data on my behalf.
  • The playground and the extension's windows load fonts from Google Fonts, which means Google sees a request from your browser.

What I do not do

  • I do not sell or share your data, run ads, or build advertising profiles.
  • I do not use your data for credit, lending or any purpose unrelated to the detector.
  • I do not read your browsing history. The extension only handles the images described above.

Your choices

Leave Passive Badge Mode off, use the extension only when you right-click, or point it at your own server under "Use your own server or key". To have log or feedback entries deleted, use the contact link below and include the file name.

Contact

Questions or deletion requests: open an issue on GitHub. Please give only the file name and do not attach the image. Issues there are public, so if you would rather keep a request private, say so in the title and I will arrange another way to continue.

Changes

If this policy changes, the date at the top changes with it.
